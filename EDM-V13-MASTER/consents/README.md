goes here. Until a consent is filed, the generalised wording is used everywhere —

## When consent arrives

1. Save the email or letter here as `khazna-pmk-consent-YYYY-MM-DD.pdf` (or .eml).
2. Update the line in `DECISIONS.md` and in `CHANGELOG.txt`.
3. Only then may the named versions publish.

The rule applies to reshares by individuals as well as company posts, and it does
not expire because a deadline is close.
