EDM PROGRESS — programme & weekly report
========================================

What it is
----------
The third piece of the thread. Measure numbers the walls and prices them.
Evidence proves they were built right. Progress puts dates on them — and
writes the Friday report for you.

How to use it
-------------
1. Open index.html in any modern browser. Phone, tablet or laptop.
2. Import takeoff — the wall register arrives from the EDM Measure file,
   grouped into zones automatically.
3. Plan tab: set the date each stage should start in each zone. That is
   the whole programme — no bar chart software needed.
4. Import evidence — open the saved EDM Evidence file and actual progress
   fills itself in from what the supervisors have signed. No double entry.
   Re-import it whenever you like; the board updates.
5. Dashboard answers "how far along is Level 3?" with a number that comes
   from signed inspections, not a walk-round guess.
6. Lookahead shows the next two weeks plus anything already late.
7. Delay log: the day a hold-up happens, log it — access, preceding trade,
   RFI, whatever it is. Close it out when it clears. Months later, that
   dated log is what wins the extension-of-time conversation.
8. Print weekly report produces the branded client report in one minute:
   summary, progress by zone, behind-plan list, lookahead, delay log.
   Use the browser's "Save as PDF" to issue it.

Before you lean on it
---------------------
- A stage only counts when a supervisor has passed it in EDM Evidence.
  The report says so on its face — that is what makes the number credible.
- Works fully offline. One save file holds plan, actuals and the log.
