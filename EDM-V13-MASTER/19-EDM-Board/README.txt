EDM BOARD — group operations
============================

What it is
----------
The Monday screen. Five projects, three markets, one glance. It reads the
files the teams already save — the weekly progress files, the cashflow
file, the site daybooks — matches them up by project name, and rolls the
whole group onto one board. Nobody types anything twice; that is the
entire point of it.

How to use it
-------------
1. Open index.html in any modern browser.
2. Load team files — select the lot in one go. It works out which file is
   which and pairs them by project name (spacing and capitals don't
   matter). Reload the fresh files each week; newer replaces older.
3. The board shows each project's completion, on-plan or behind, open
   constraints, labour at the last daybook count, and its money —
   certified unpaid, overdue, retention held.
4. "Needs attention this week" gathers the red items from everywhere:
   stages past their planned start, money past its due date, retention
   releases gone unclaimed, constraints still open.
5. Print weekly summary is the exec-table page: group numbers, the
   by-project table, the attention list. Save as PDF from the browser
   and the Monday meeting starts with facts.

Two things to know
------------------
- Project names must match across the tools — "Marina Tower" in Progress
  pairs with "Marina Tower" in Cashflow and the Daybook. Agree the name
  once, at tender stage, and everything links itself.
- Every figure traces back to a working file: a signed inspection, a
  logged application, a daybook entry. The summary says so on its face.
